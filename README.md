# Semana 1: Formulario de Registro Corporativo 🚀

¡Hola! Este es mi primer proyecto en el camino para convertirme en Desarrolladora Full Stack.

## 📋 Descripción del Proyecto
Este proyecto consiste en un formulario de registro interactivo, estructurado con etiquetas HTML5 semánticas, validaciones nativas y maquetado básico con CSS.

## 🛠️ Tecnologías y Conceptos Aplicados
- **HTML5:** Estructura semántica, uso de `<fieldset>`, `<legend>`, `<datalist>`, campos de entrada variados (`text`, `email`, `password`, `date`, `range`, `color`, `file`).
- **Atributos UX:** `autofocus`, `readonly`, `required`, `placeholder`.
- **CSS3:** Maquetación básica y diseño de formularios.
- **Git & GitHub:** Control de versiones, configuración de firma privada no-reply y flujo de commits.
